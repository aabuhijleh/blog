Two components I use in posts. Both take plain data props, so they work anywhere MDX does.

import { FileExplorer } from "~/components/file-explorer";
import { PackageCommand } from "~/components/package-command";
import { blogSource } from "./explorer";

## Package manager commands

Write the npm version of a command. The component derives the pnpm, yarn, and bun equivalents.

```tsx
import { PackageCommand } from "~/components/package-command";

<PackageCommand client:visible command="npx shadcn@latest add accordion" />;
```

<PackageCommand client:visible command="npx shadcn@latest add accordion" />

Picking a tab writes the choice to `localStorage` and every other block on the site follows it.

<PackageCommand client:visible command="npm install -D vitest" />

<PackageCommand client:visible command="npm run dev" />

Pass `commands` to override any of the four when the translation is wrong.

```tsx
<PackageCommand
  client:visible
  command="npm install sharp"
  commands={{ bun: "bun add sharp --trust" }}
/>
```

## File explorer

Click a folder to open it, click a file to read it. Arrow keys move through the tree, and `Enter` opens the focused folder or reads the focused file.

```tsx
import { FileExplorer } from "~/components/file-explorer";

<FileExplorer
  label="Blog source"
  tree={[
    {
      name: "src",
      children: [
        { name: "consts.ts", content: `export const SITE_AUTHOR = 'Abed';` },
      ],
    },
  ]}
/>;
```

<FileExplorer
  label="Blog source"
  defaultExpanded={["src", "src/components"]}
  tree={blogSource}
/>

`defaultExpanded` takes folder paths. Leave it out and the top level opens on its own.

Give a file a `content` string and Shiki highlights it during the build, with the same nord theme as the code blocks above. The browser gets the finished HTML, so no highlighter ships to the client. A file without `content` still sits in the tree, it just has nothing to show.

One catch. MDX strips the leading spaces off every line inside a JSX expression, so a multi-line string written in the post comes out flat. Keep those files in a `.ts` module next to the post and import the tree, the way the explorer above does.
